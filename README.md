# TissUUmaps website

[![Deploy](https://github.com/TissUUmaps/tissuumaps.github.io/actions/workflows/deploy.yaml/badge.svg)](https://github.com/TissUUmaps/tissuumaps.github.io/actions/workflows/deploy.yaml)

The [TissUUmaps](https://github.com/TissUUmaps/TissUUmaps) website, built with [Docusaurus](https://docusaurus.io/).

The documentation is written in the TissUUmaps repository.
Only the documentation and the app are versioned, by MAJOR.MINOR line.

## Releases

On every release, the TissUUmaps release workflow pushes the released docs to `releases/<line>/`:

- `release.json` holds the released `version`, e.g. `{ "version": "4.1.2" }`.
- `docs/` holds the docs, including the API docs generated by typedoc.

Every push to `main` deploys the website.
Before the build, `scripts/prepare.ts` turns the released lines into Docusaurus versions.
It also downloads their apps from the TissUUmaps releases, served under `app/<line>/`.
A prerelease line is only shown while it is ahead of the latest stable line.

To build the released versions locally (downloading the apps needs `gh`):

```bash
pnpm install
pnpm run prepare:site # or: pnpm run prepare:site --skip-apps
pnpm run build && pnpm run serve
```

## Local preview

Clone this repository next to a TissUUmaps checkout and generate the API docs there:

```bash
cd ../TissUUmaps
pnpm install
pnpm run build:packages && pnpm run build:apidocs
```

Then start the website with the TissUUmaps docs as the current version:

```bash
pnpm install
TISSUUMAPS_DOCS=../TissUUmaps/docs pnpm run start
```

Most changes, including changes to the TissUUmaps docs, are reflected live.
The preview shows the TissUUmaps docs as "Next", next to any prepared released versions.
