# Getting started

From your first look to sharing your own data.

<Steps>

## Open TissUUmaps

TissUUmaps runs in your browser, with nothing to install.

<Button to="pathname:///app/">Open TissUUmaps</Button>

## Explore an example

Open a project from the gallery. Pan and zoom in the viewer. Show, hide or restyle each image, label image, point cloud and shape cloud in the **Images**, **Labels**, **Points** and **Shapes** tabs.

<Button to="/gallery">Gallery</Button>

## Add your own data

<Columns>
<Box title="Local data" note="Chrome, Edge and other Chromium-based browsers only. Not available in Firefox or Safari.">

Drag the folder with your data onto the **Project** tab and open it as the workspace. Then drag files or folders, such as an OME-Zarr store, from the workspace onto the **Images**, **Labels**, **Points**, **Shapes** or **Tables** tab. TissUUmaps recognizes the format, fills in the add dialog and starts a project if none is open.

</Box>
<Box title="Cloud data" note="All browsers.">

Click **Start empty** in the **Project** tab. Then click **Add** in the **Images**, **Labels**, **Points**, **Shapes** or **Tables** tab and paste the URL of your data. The server must allow cross-origin requests (CORS).

</Box>
</Columns>

See the [supported data](/docs/supported-data) for the formats and their settings.

## Open a SpatialData store

TissUUmaps opens SpatialData stores as projects. In the **Project** tab:

- **From a URL:** click **From URL…** (or **Open from URL…** in the project menu) and paste the URL of the store (the `.zarr` folder).
- **From your computer:** drag the store's `.zarr` folder onto the **Project** tab and choose **Open as project**. Chromium-based browsers only.

Each coordinate system becomes a layer, and each element becomes an image, labels, points or shapes object. Only the first element of each layer is shown at first. Show the others in the side panel.

To link to a store, add its URL to the TissUUmaps link, for example:

```
https://tissuumaps.github.io/app/4.0/?spatialdata=https://tissuumaps4.serve.scilifelab.se/data/xenium_512.zarr
```

<Button to="pathname:///app/4.0/?spatialdata=https://tissuumaps4.serve.scilifelab.se/data/xenium_512.zarr">
  Open this example
</Button>

See [SpatialData](/docs/supported-projects/spatialdata) for the details and limitations.

## Save and share

A project file (`.tm4`) describes your data and how to show it, but does not contain the data. With a workspace open, **Save as…** in the project menu saves it to a file in the workspace, and **Save project** saves later changes to that file. Without a workspace, **Download project** downloads it. Drop the file on the **Project** tab to open it again.

To share a project, put the project file and the data on a web server, and add the project file's URL to the TissUUmaps link:

```
https://tissuumaps.github.io/app/?project=https://example.org/project.tm4
```

Paths in the project file can be relative to it, so the project folder can move without editing the file. See [Projects](/docs/concepts/projects).
